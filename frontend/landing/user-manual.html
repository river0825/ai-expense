AI Expense User Manual

This manual is based on the currently implemented features in code, focused on practical user flows.

1. Quick Start 2. Chat Tracking 3. Report Link & Access 4. Dashboard Features 5. Settings 6. Quick-start Video 7. Release Notes

1. Quick Start

  1. Add AI Expense bot (commonly LINE in public deployment).
  2. Send an expense message, for example: "Lunch 180".
  3. The system auto-registers your account and records the expense.
  4. Send "report" to get your personal report link.

2. Chat Tracking

Supported input examples:

Basic

Breakfast 80

With Account

Dinner 320 Credit Card

Multi-currency

Tokyo ramen 1200 JPY

Relative Date

Yesterday coffee 120

  • If account is omitted, default account is "Cash".
  • System returns category, amount, currency, and account.
  • One message may be parsed into multiple expenses.

3. Report Link & Access

  • Keywords include: report, summary, stats, analysis.
  • System generates a short link like /r/{id} to your dashboard.
  • After opening, your data is loaded via secure token flow.

4. Dashboard Features

4.1 Overview

  • Date range filters (preset + custom).
  • Account filter (Cash, Credit Card, etc).
  • Cards: total spend, count, average, top category.
  • Charts: category breakdown and trend (day/week/month).

4.2 Expense List

  • Search, sorting, and grouping.
  • Inline edit: description, amount, currency, account.
  • Home-currency preview while editing.

5. Settings

5.1 Home Currency

Set your home currency for aggregated display and reports.

5.2 Category Management

  • Create category (name + description).
  • Edit or delete custom categories.
  • Merge categories when duplicate name is detected.
  • Default categories are protected.

5.3 Accounts

Current version supports account listing; advanced edits are planned.
