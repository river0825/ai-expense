# AIExpense Admin Panel

This is the admin panel for the AIExpense system. It allows administrators to manage users, view metrics, and configure system settings.

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui + Radix UI
- **Runtime**: Bun

## Getting Started

### Installation

```bash
cd frontend/admin
bun install
```

### Development

```bash
bun run dev
```

The admin panel will be available at `http://localhost:3000`.

### Build

```bash
bun run build
bun start
```
