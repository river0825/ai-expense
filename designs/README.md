# AIExpense Landing Page Design

**設計檔案：** `aiexpense-landing-page.pen`
**建立日期：** 2026-02-07
**設計工具：** Pencil Design System

## 設計概述

這是 AIExpense 產品的 landing page 視覺設計，專注於：
- 家庭日常記帳（主要場景）
- 群組分帳和個人記帳（次要場景）
- 在既有通訊軟體（LINE、Telegram）中無縫操作

## 設計架構

### 1. Hero Section（英雄區）
- **標題：** 在聊天中記帳，輕鬆分享開支
- **副標題：** 說明不需要下載新 app，直接在 LINE/Telegram 中使用
- **背景色：** #FFF3E6（溫暖的奶油色）
- **CTA 按鈕：**
  - 主按鈕（橙色 #FF9966）：立即開始使用
  - 副按鈕（邊框）：了解更多

### 2. 三步流程區（Steps Section）
背景色：#FFFFFF

三個步驟卡片：
1. **🤖 加入機器人** - 在 LINE 或 Telegram 加入機器人
2. **💬 聊天記帳** - 像聊天一樣說出開支
3. **📊 自動分析** - 自動分類和生成報告

### 3. 互動展示區（Demo Section）
背景色：#FFF3E6

展示手機模型中的對話流程：
- 用戶訊息（橙色背景 #FF9966）
- 機器人回應（灰色背景 #F0F0F0）
- 展示功能：支付方式、多幣別、自動分類、群組分享

### 4. 使用場景區（Scenes Section）
背景色：#FFFFFF

四個並排卡片，各有不同配色：
1. **👤 個人記帳** - #FFF9F5 背景，#FF9966 標題
2. **👨‍👩‍👧 家庭共享** - #F0FFF4 背景，#9FD356 標題（綠色）
3. **👥 群組分帳** - #F0F7FF 背景，#87CEEB 標題（藍色）
4. **📈 智慧分析** - #FFF9F5 背景，#FF9966 標題

### 5. 最終 CTA 區（Final CTA Section）
背景色：#FFF3E6
- **標題：** 準備好輕鬆記帳了嗎？
- **副標題：** 現在就加入使用，開始簡化你的家庭財務管理
- **按鈕：** 同 Hero Section

### 6. Footer（頁腳）
背景色：#333333（深灰色）

內容：
- 品牌標誌：AIExpense（橙色）
- 標語：聊天，記帳，生活更輕鬆
- 導航連結：產品、公司相關
- 法律連結：隱私政策、使用條款
- 版權資訊

## 版面寬度
- **設計寬度：** 1440px（台式電腦標準）
- **內容寬度：** fill_container（響應式）
- **邊距：** 120px 水平、80px 垂直

## 字體系統
- **字體家族：** Inter（現代、易讀）
- **標題大小：** 48-56px（H1）、42px（H2）、28px（H3）
- **正文大小：** 16-18px
- **小字大小：** 12-14px
- **字重：** normal、semibold、bold

## 圓角設計
- **大圓角：** 24px（手機邊框）
- **中圓角：** 16px（對話氣泡、卡片）
- **小圓角：** 8px（按鈕）
- **邊框寬度：** 2px（邊框按鈕、場景卡片邊框）

## 開發注意事項

### 響應式設計考量
- **桌面版（1440px）：** 四個場景卡片並排顯示
- **平板版（768-1023px）：** 場景卡片改為 2x2 網格
- **手機版（< 768px）：** 場景卡片垂直堆疊，Demo 手機模型居中

### 互動元素
- CTA 按鈕應有 hover 效果（如陰影加深或背景深化）
- 卡片應支持 hover 動畫（如輕微升起或邊框顏色變化）
- 頁面應支持平滑滾動

### 實現建議
1. **Next.js 組件化設計** - 建議按區段拆分為獨立組件
2. **Tailwind CSS** - 使用 Tailwind 的色彩系統對應上述色彩
3. **圖片優化** - Demo 區域的手機模型可使用 SVG 或圖片
4. **可訪問性** - 確保色彩對比度符合 WCAG AA 標準
