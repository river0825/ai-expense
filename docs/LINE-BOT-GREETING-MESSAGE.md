## 🎨 設計原則

### 視覺和語氣
- ✅ **親切友善** - 使用適量 emoji，但不過度
- ✅ **清楚簡潔** - 避免過長的文字塊
- ✅ **行動導向** - 每個訊息都有明確的下一步
- ✅ **鼓勵互動** - 邀請用戶嘗試功能
- ✅ **專業可靠** - 傳達信心和能力

### 訊息長度
- 主歡迎訊息：150-200 字
- 指引訊息：100-150 字
- 選項訊息：50-100 字

### 快速回覆按鈕
- 最多 4-5 個按鈕（避免過多）
- 使用 emoji + 短文字（5-8 字）
- 清楚指示下一步行動

## 🚀 部署建議

### 實施步驟
1. 在 LINE Messaging API 中設定 Welcome Message
2. 連接 Webhook 處理後續互動
3. 根據 postback data 執行相應動作
4. 保存用戶的設定選擇到數據庫

### LINE Bot 工具
- **LINE Official Account Manager** - 設定自動回覆和歡迎訊息
- **Messaging API** - 程式化發送豐富訊息
- **LINE Bot Designer** - 視覺化設計對話流程
