# User Journeys

這個目錄用來保存「使用者會怎麼使用系統」的文件。

這些文件不是規格書，不談內部實作細節，而是聚焦在：

- 使用者在什麼情境下會來使用
- 使用者會輸入什麼
- 系統會回應什麼
- 使用者下一步通常會做什麼

## 標註規則（PO 視角）

- `【已開發】`: 已在目前系統可使用，並有程式/測試可追溯
- `【尚未開發】`: PO 想像中的未來體驗，尚未在目前版本上線

## 文件清單

- `index.md`: 目前系統所有已存在 user journeys 的總覽清單
- `po-qa.md`: PO 可直接回答的問題與目前可對外描述範圍
- `engineering-questions.md`: 過深工程細節與待資深工程師確認問題
- `engineering-backlog.md`: 工程整理待辦（優先級與可執行項）
- `add-expense-variants.md`: Add Expense 主旅程與各種變型（單筆、多筆、幣別、wallet/account 等）
- `currency-journeys.md`: 幣別相關旅程整合（關鍵字切換、旅行建議、輸入/本位幣分離）
- `first-time-auto-signup.md`: 第一次使用者如何自動註冊並直接開始使用
- `report-link-to-dashboard.md`: 查報表到進 dashboard 的流程
