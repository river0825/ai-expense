# 使用者旅程：第一次使用自動註冊

狀態：`【已開發】`

## 這份文件是做什麼的

描述新使用者第一次跟系統互動時，如何在不需要額外註冊步驟的情況下，直接完成啟用並進入記帳流程。

---

## 角色與情境

- 角色：第一次使用 AIExpense 的使用者
- 情境：透過聊天介面（例如 terminal / LINE）第一次傳訊息

---

## 旅程步驟

### Step 1：使用者直接傳第一則訊息

使用者輸入（示例）：

```text
午餐 120
```

重點：

- 使用者不需要先走獨立註冊流程
- 直接從「想記帳」開始

### Step 2：系統自動建立使用者與預設分類

系統行為：

- 建立 user record
- 建立預設分類（Food / Transport / Shopping / Entertainment / Other）

重點：

- 把 onboarding 隱藏在第一次互動中
- 降低首次使用門檻

### Step 3：同一則訊息繼續進入正常解析與記帳

系統行為：

- 解析訊息中的金額與描述
- 建立 expense
- 回傳成功訊息

---

## 使用者價值

- 不會被註冊流程打斷
- 第一次互動就有成果（成功記帳）

---

## PO 想像（未來版本）

- `【尚未開發】` 新手導引訊息：第一次成功記帳後，系統可引導使用者完成「查報表」與「設定預設幣別」。
- `【尚未開發】` 個人化預設：根據地區與常見消費，初始化更貼近使用者的分類與帳戶選項。
