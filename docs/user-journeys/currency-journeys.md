# 使用者旅程：幣別相關旅程（整合）

狀態：`【已開發】`（主流程）

## 這份文件是做什麼的

整合目前所有「幣別」相關的使用者旅程，包含：

1. 關鍵字切換預設輸入幣別
2. 旅行情境下主動建議切換幣別
3. 輸入幣別與本位幣分離（default input vs home currency）

---

## Journey A：關鍵字切換預設輸入幣別

狀態：`【已開發】`

### 典型對話

使用者：

```text
把預設幣別改成 JPY
```

系統：

```text
已更新，預設幣別現在是 JPY。
```

### 使用者價值

- 不需進設定頁，也能快速調整幣別
- 透過聊天完成偏好設定

---

## Journey B：旅行情境主動建議切換幣別

狀態：`【已開發】`

### 典型對話

使用者：

```text
我正在日本旅行
```

系統：

```text
您好，我偵測到您正在日本旅行，這是預設的貨幣嗎？
```

使用者：

```text
ok
```

系統：

```text
已切換，接下來的記帳都會預設為 JPY。
```

### 使用者價值

- 不用記命令也能完成設定
- 以對話引導取代繁瑣設定流程

---

## Journey C：輸入幣別與本位幣分離

狀態：`【已開發】`

### 情境

- 使用者輸入幣別：JPY
- 使用者本位幣：TWD

### 系統行為

- 記帳時以 JPY 解讀輸入金額
- 儲存原始幣別與金額
- 同時換算並顯示本位幣（TWD）

### 使用者價值

- 旅行時輸入自然，報表比較仍穩定
- 避免每筆手動補幣別

---
